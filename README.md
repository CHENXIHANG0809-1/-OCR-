运行平台：
Windows 64位，Python 3.11 64位，CPU推理。
Python取 3.11是因为只找到了兼容3.11的OCR模型，有能力者可以自行判断更改配置文件。经作者验证当前PADDLEOCR对于3.11任意版本可用，3.14任意版本不可用。

首次使用：
1. 将压缩包完整解压到本地目录，请务必确认是独立目录例如 D:\GujiOCR。相关安装可使用清华大学镜像https://mirrors.tuna.tsinghua.edu.cn/python/3.11.0/，我内置了AMD64版本。
2. 安装Python 3.11 64位（默认C盘即可），并勾选Python Launcher组件和PATH（环境变量）。
3. 双击install.bat，等待依赖安装和模型检查结束（下载共104行，读取完后会不动一段时间，光标会变到行首而非显示路径；这是在进行下载，下载完成后会自动运行check，一切正常会显示）。
4. 出现类似“检查结束，未发现错误“”后，双击start.bat。此时会出现一个广告页面，随意输入邮箱后即可实现映射。注意整个映射过程由命令行发出，因此全过程不可关闭命令行窗口（可以最小化挂后台，无影响）。
5. 浏览器访问 http://127.0.0.1:8501，IE浏览器架构不兼容，需使用edge Google等。

日常使用：
双击start.bat即可。导入文件、页面图像和识别结果自动保存在data目录。
若提示无法访问此页面/拒绝连接，检查是否关闭了powershell窗口。这是由于未成功映射到浏览器
若提示8501端口被占用，先检查是否已经启动了一个（包括powershell命令行及浏览器），不要连续双击多个启动窗口。
脚本将服务限制在127.0.0.1，只允许本机访问，不会主动开放给局域网其他设备。
平时powershell窗口可以用cmd指令调起，方法为win+R，输入cmd。若需使用本软件最好在你保存软件的文件夹目录中空白处右键-在终端打开。cmd之间只要不共用端口不会冲突可以多开并行。

迁移：
将项目复制到另一台电脑后，重新运行install.bat。
不要复制或沿用其他电脑上的.venv虚拟环境。（即不要直接复制文件夹。虚拟环境包含与原电脑相关的路径，应通过脚本在新机重新创建环境；data目录则因为其中可能有导入的文献、识别结果和原始文件）
如果安装后移动了项目目录，建议删除.venv再重新安装。（否则会提示被占用）

卸载：
目前的方案没有注册Windows服务、修改系统PATH或写入注册表，依赖都安装在项目内部的.venv中，所以关闭程序后，删除整个项目文件夹就完成了卸载。
不过，data目录保存着原始文献、页面图片、OCR结果和人工校对文本，如果希望彻底卸载，可以直接使用uninstall.bat
注意，这个脚本会删除所在目录中的其他文件和子目录，所以前面说不要把项目解压后混放到桌面根目录、下载目录或存有其他文件的文件夹里。正确的位置应当是独立目录
对计算机架构不熟悉的使用者可以直接仅删除整个项目文件夹，影响不大

警告：
不要随意升级PaddlePaddle、PaddleOCR或修改模型字典。
